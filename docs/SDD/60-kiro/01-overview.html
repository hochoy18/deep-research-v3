🥈 Kiro (AWS) · AI IDE 中的 spec-driven 模式

Kiro 是 AWS 推出的 AI IDE,把 spec-driven development 思想融入 IDE 本身,适合"在 IDE 里一站式完成"的场景。

AWS 出品 IDE 集成 看场景

🥈 Kiro (AWS)

一句话:AWS 出的 SDD 完整 IDE 工具

发现阶段:Specs 三件套(requirements / design / tasks)

强项:企业级、UI 完整、Requirements-First/Design-First 两种

弱项:绑定 Kiro IDE、生态封闭

安装:Kiro IDE

🥇 awesome-claude-skills

📑 Kiro 详细能力

11. Kiro (AWS) 看场景

定位:AWS 的 SDD 完整 IDE 工具,Specs 三件套

核心能力:requirements.md / design.md / tasks.md

优势:

  • ✅ 企业级、UI 完整
  • ✅ Requirements-First / Design-First 两种模式

劣势:

  • ❌ 绑定 Kiro IDE(生态封闭)
  • ❌ 闭源(AWS)
  • ❌ 与 spec-kit 互斥

适合:愿意换 IDE 的企业团队

12. OpenSpec propose 推荐

🔗 spec-kit + Kiro 组合

Kiro 自身已包含 spec 流程,通常不需要再叠加 spec-kit。但 Kiro 输出的 spec 文档可以喂给 spec-kit 的 /speckit-specify 命令做后续拆解。
