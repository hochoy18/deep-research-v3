🥇 OpenSpec · 发现阶段 SDD 框架

OpenSpec 是 Fission AI 开源的 Spec-Driven Development 框架,通过 /opsx:explore、/opsx:propose 等命令把"想法"转化为可执行的 spec。

Fission AI 出品 spec-kit 友好 4 个核心命令 中等学习曲线

🥇 OpenSpec

一句话:SDD 框架,4 命令轻量流程

发现阶段命令:/opsx:explore

强项:轻量、灵活、无重型仪式

弱项:与 spec-kit 思路略不同(单 change 目录 vs specs/ 目录)

安装:npm install -g @fission-ai/openspec@latest

🥇 Superpowers

🔗 spec-kit + OpenSpec 组合

组合 2:spec-kit + OpenSpec

分工:

  • OpenSpec explore — 探索阶段
  • OpenSpec propose — 创建 change(可选,如果想用 OpenSpec 格式)
  • spec-kit /speckit-constitution — 宪法
  • spec-kit /speckit-specify — feature spec

适用:同时用 OpenSpec + spec-kit 的人群

组合 3:spec-kit + agentic-awesome-skills(按需挑)

🚀 5 分钟起步:OpenSpec explore

10 分钟起步:试用 OpenSpec explore

# 1. 安装:
npm install -g @fission-ai/openspec@latest
cd /path/to/your-project
openspec init

# 2. 试试 explore:
> /opsx:explore 我们想做一个新功能,有什么方案?
```

⚖️ 优缺点总结

维度评价
易上手🟢 命令式触发,文档清晰
与 spec-kit 协作🟢 输出 spec 文档,可直接复用
团队协作🟡 需配合 git workflow
生态成熟度🟡 新兴项目,Star 较少
