📚 awesome-claude-skills & agentic-awesome-skills

两个大型 skills 集合仓库,按需挑拣,适合"想要什么 skill 都能找到"的场景。

1000+ skills 2689+ skills 按需挑

1. awesome-claude-skills 1000+

🥇 awesome-claude-skills

一句话:1000+ Claude Skills 目录

发现阶段 skill:brainstorming、deep-research、recursive-research

强项:中英文混合、覆盖面广

弱项:不是完整 SDD,需要自己拼装

安装:cp -r skill-name ~/.config/claude-code/skills/

🥇 agentic-awesome-skills

2. awesome-claude-skills 1000+ 推荐

定位:Claude Skills 目录,从中挑 1-2 个

核心能力:包含 brainstorming、deep-research、recursive-research

优势:

  • ✅ 覆盖面广(1000+)
  • ✅ 中英文混合
  • ✅ 单文件复制即用

劣势:❌ 不成体系,自己拼装

适合:在 brainstorming 之外,想加 research 能力

2. agentic-awesome-skills 2689+

🥇 agentic-awesome-skills

一句话:2689+ skills 大全,场景化

发现阶段 skill:brainstorming、before-you-build、idea-autopsy、what-could-break、rich-elicitation

强项:精准场景化(skills 可按需挑)

弱项:需要自己挑,新手不知道选哪个

安装:npx agentic-awesome-skills --skills brainstorming,before-you-build

🥈 Marvin

3. agentic-awesome-skills 2689+ 强烈推荐

定位:场景化 skills 集合,按"建前审查"挑

核心能力:包含 brainstorming、before-you-build、idea-autopsy、what-could-break、rich-elicitation

优势:

  • ✅ 精准场景化(每个 skill 对应一个明确场景)
  • ✅ 16+ 平台支持
  • ✅ 与 spec-kit 友好

劣势:❌ 新手不知道选哪个(5 个 skill 容易选错)

适合:已经有 RFC,想用 1-2 个 skill 做"建前审查"

🔗 spec-kit + 按需挑拣组合

组合 3:spec-kit + agentic-awesome-skills(按需挑)

分工:

  • brainstorming — 任何需要发现时
  • before-you-build — RFC 之前审查
  • idea-autopsy — 想法尸检
  • what-could-break — 爆炸半径评估
  • rich-elicitation — 扫 PRD 收边界
  • spec-kit — 走完整流程

适用:想要"按场景挑 skill"的人

组合 4:spec-kit + Marvin(纯 Python)

💡 怎么用

  • 先在 README 搜你需要的 skill(如 "brainstorm"、"grill")
  • 把单个 skill 的 SKILL.md 复制到 ~/.claude/skills/<name>/SKILL.md
  • 不要整包安装,会污染 prompt
