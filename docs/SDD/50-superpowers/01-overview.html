🥇 Superpowers · Claude Code 官方插件

Superpowers 是 Anthropic 官方维护的 Claude Code 技能包,提供 brainstorming、writing-plans、test-driven-development 等核心 skill,直接装就能用。

Anthropic 官方 高质量 skill 持续更新 推荐优先试用

🥇 Superpowers

一句话:Claude Code 官方插件市场的方法论 + skills 框架

发现阶段 skill:brainstorming

强项:强制发现、TDD、Code Review 全套

弱项:绑定 Claude Code(不支持其他 IDE)

安装:/plugin install superpowers@claude-plugins-official

🥈 Kiro (AWS)

🔗 spec-kit + Superpowers 组合 ⭐⭐⭐⭐⭐

这是本项目最推荐的发现阶段组合。Superpowers 的 brainstorming skill 帮你从模糊想法生成清晰 PRD,spec-kit 接着把 PRD 变成可执行 spec。

组合 1:spec-kit + Superpowers ⭐⭐⭐⭐⭐(最推荐)

分工:

  • Superpowers brainstorming — 强制发现阶段
  • Superpowers writing-plans — 任务拆分(替代 /speckit-tasks)
  • Superpowers test-driven-development — 强制 TDD
  • Superpowers requesting-code-review — Code Review
  • spec-kit /speckit-constitution — 项目级宪法
  • spec-kit /speckit-specify — feature spec(超 1 个时用)
  • spec-kit /speckit-plan — 技术方案
  • spec-kit /speckit-converge — 收敛判定

适用:本项目,大多数场景

组合 2:spec-kit + OpenSpec
