核心理念

用"先写 spec,再写代码"的纪律,让 AI 在严格的规格边界内高效工作。本站汇集 GitHub spec-kit、Matt Pocock 的 Grill/OpenSpec/Superpowers 等主流方案,帮你选对工具、用对方法。
